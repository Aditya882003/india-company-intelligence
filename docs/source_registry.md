# Source registry

## Market / price

| Source | Purpose | Mode |
|---|---|---|
| Yahoo Finance / yfinance | Live quote + intraday + historical daily prices | Public interface, may be rate-limited |
| NSE India | Independent quote verification | Public quote endpoint when reachable |
| NSE Data & Analytics | Professional exchange-grade real-time feed | Paid/licensed |
| Upstox Developer API | Optional real-time WebSocket feed | Authenticated; requires developer access token |
